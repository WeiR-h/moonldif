## 本轮发现与处理

1. 第一轮 CLI 集成中，MoonBit Option 的自动 JSON 表达不是预期的 string/null，造成路径传入数组。修正为显式转换，中文路径、读写及策略集成测试复验通过。
2. 原始逐行字符串拼接会在大量小折行时重复复制。改为缓冲写入，并使用 20,000 个小续行和超限样本验证。
3. 官方包管理器下载 async 0.20.3 出现 TLS handshake EOF。通过系统下载器获取同一官方版本，再按 SHA-256 校验，使用官方本地工作区机制完成编译测试。没有关闭 TLS 校验或修改包缓存。
4. 参考 Python 解析器对部分错误 Base64 较宽松、对变更类型的回调覆盖也不统一，因此只在已确认的内容与 modify 接口上作独立对照；其他行为由明确规则与测试单独验证。
