## 已发现与保留的限制

- SDK 的空控制值异常及整项 Base64 扩展单独记录；不通过删掉样例使报告变绿。
- RFC 原刊的部分示例有排版或折行问题，修订性质分别标明，不能把所有修订都称为官方已确认勘误。
- 当前写回大文件仍消耗数百 MiB 进程内存；有界完整缓冲区不是流式库。
- 不验证目录 Schema、DN 匹配语义、BER 断言语义、服务端状态/ACL 或真实导入结果。
