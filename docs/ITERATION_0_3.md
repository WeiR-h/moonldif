# 0.3.0 批量离线预检迭代

本轮增加 CLI `batch INPUT...` 与 MoonBit BatchReview 公共 API，面向同一变更提交中的多份 LDIF。按显式输入顺序逐份检查，输出 text / JSON / Markdown 汇总；2 优先于 1，空输入拒绝，个别文件失败不会丢弃其他文件发现的风险。

最多 50 个显式文件、每文件 8 MiB、批次累计接受输入的总字节 32 MiB。不做目录遍历、通配符展开、LDAP 写入、Schema、自动修复或跨文件语义合并。重复路径按显式输入重复检查，序号区分同名文件。CLI 报告仅包含文件基本名，不附加绝对目录；仍包含 DN。

核心负责策略、摘要、指纹格式检查、资源计数与报告；Node 仅负责有界文件读取、SHA-256 与进程退出。API 的指纹由宿主针对实际字节提供，不是签名。报告保留每文件原有字段，生成过程无变化的时间戳。

交付门槛：核心双目标、真实 CLI 混合结果和资源边界回归、独立对照、双平台 CI、批量接入示例、正式包/注册表安装复验、同版本公开工作台回归。0.2.0 继续保留；未发布前不宣称 0.3.0 已交付。
