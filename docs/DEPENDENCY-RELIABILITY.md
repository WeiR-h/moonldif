# 固定依赖下载与故障恢复

0.4.0 收尾时 Windows CI 曾因 WinError 10054 中断下载，重跑后通过。0.5.0 为 `prepare-moonldap.py` 的两份固定 MoonBit 生态依赖增加有限恢复能力，不改变依赖来源、版本或哈希。

- 只接受 HTTPS，使用 Python 默认 TLS 校验。按照 [Python 官方异常分类](https://docs.python.org/3/library/urllib.error.html) 区分 HTTP、网络、证书与本地错误。
- 临时超时、连接中断、部分响应及 HTTP 408 / 429 / 500 / 502 / 503 / 504 最多尝试三次，间隔 0.5、1 秒。每次 socket 超时 35 秒；这不是整个请求的墙钟时限。
- 证书失败、哈希不符、超限、永久 HTTP 错误、本地写入失败直接退出。现有坏缓存保留并明确拒绝，不自动当作成功。
- 单个下载最多 16 MiB，先验证固定 SHA-256，再在同目录创建临时文件并原子替换。失败不会留下可误用的半份缓存；临时文件清理。
- 归档路径与符号链接的现有解压检查继续保留。不读取 LDIF 外部值，不连接 LDAP 服务器。

`python scripts/test_pinned_download.py` 使用本地故障注入验证中断后成功、三次超时、部分响应、证书错误、HTTP 分类、错误哈希、坏缓存、大小限制及原子替换失败。它不是远程服务可靠性或第三方试用的证明。

CI 的 MoonBit 安装器、npm 安装和其他独立参考下载仍使用各自流程；本轮没有声称修复所有网络问题。
