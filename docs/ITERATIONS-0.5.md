# 0.5.0 四轮迭代

开始日期：2026-09-20。沿用 LDIF 文件读写与离线预检方向，9 月 23 日冻结新增功能。

1. **可审计的比较范围**：MoonBit API / CLI 支持显式排除属性描述；默认不排除，规范化列表和实际命中数进入报告。排除不跳过语法验证、外部值、重复 DN 或整条条目增减。修复报告对象被调用者修改和属性选项去重的稳定性问题。
2. **更容易审阅**：工作台提供排除项、差异类型及 DN / 属性名称查找、明确的筛选与截断提示、停止核对。筛选只影响显示，下载保留完整有界报告；编辑与选项变更使结果失效。
3. **可复现的依赖准备**：对临时网络故障有限重试；先验证固定哈希再原子写入缓存。证书、哈希、永久 HTTP 错误不绕过，不无限重试。用本地故障注入验证。
4. **交付复验**：固定种子独立模型、双目标、CLI、浏览器、独立参考及 Windows / Ubuntu CI；公开发布、注册表消费、Pages 和个人验收资料分别记录。

每轮按实际阶段提交。测试不代表真实用户使用、服务端语义相等、最终验收或获奖。新版本通过前保留 v0.4.0 正式基线。
