# 三轮收尾与 GitHub 交付

当前版本：0.1.0-dev.5。本次用户明确授权继续 1–5 轮迭代并推送 GitHub；mooncakes 发布仍单独待授权。尚未将本页计划当作已经公开或通过 CI。

1. **批量审阅实用性**：文本报告补属性名和给定值数量；网页直接显示目标 DN。两个条目修改同一 mail 属性时能直接区分目标，第二项定位准确。32 个核心测试及 9 组 CLI 已在本机通过；保留未知操作和不完整写出阻断。
2. **独立源码复现和发布内容**：按最终 Git 源码创建不带 dist、node_modules、本机配置和缓存的新目录；分别验证核心、CLI、浏览器构建。归档接入和独立参考另有证据。源码及历史排除凭据和工具链，依赖许可随浏览器构建输出。
3. **GitHub 和远端 CI**：待从授权账号创建公开仓库并推送，然后记录 Windows/Ubuntu 的实际执行结果；失败需要修正后重跑。

完整研发、规范、SDK、上游数据及浏览器证据按版本保留在 `verification/`。主办方审核、获奖、真实目录执行和企业用户采用均未发生，不由工程测试替代。
