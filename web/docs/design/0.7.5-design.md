# v0.7.5 workbench design

Design brief: improve the existing offline engineering workbench, preserving every control, input, report, sample and state transition. No marketing surface, remote assets, analytics or new analysis capability.

The Image Gen reference uses a navy header (#122d3c), cool gray page (#f4f7fa), white panels, teal actions (#176b62), thin borders and 8px corners. A horizontal mode navigation leads to the existing title/actions, then the full-width analysis status. Desktop uses a left rules/configuration rail and a source/results workspace. Snapshot mode uses the same rail and two source panels with its existing difference list. Inputs remain code-native; no raster is loaded by the product.

Typography: system Segoe UI / Microsoft YaHei, 28px page titles, 16px panel titles, 13–14px chrome, 14px monospace source with existing 26px line geometry. Outline icons retain the current local SVG family. Focus rings, disabled state and wrapping stay explicit. Main mobile actions are at least 42px tall. At 1200px source/results stack; at 800px the rail becomes full width; at 480px controls use the narrow-screen layout without horizontal page overflow.

Allowed copy: all existing UI labels and explanations; one new section label, 检查规则. Do not rename buttons or change aria labels. Preserve the full risk and report privacy notices. Reference simplifications of sample text, syntax coloring, numeric row decorations and simplified pagination are intentionally not adopted: retain exact synthetic inputs, textarea selection/line mapping, complete pagination and full rule/error explanations. No new runtime dependency or font request.

Verification: compare header, navigation, palette, typography, status emphasis, panel alignment and responsive layout against the reference; verify real precheck, profile errors, navigation, migration comparison, full report saving and stale-result invalidation in the built-in browser, plus existing two-engine regression.
