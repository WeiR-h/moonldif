# 工作台设计与实测

设计来源：内置 Image Gen 生成 `workbench-concept.png`，本轮采用为实现参照；不是产品中的栅格 UI。生成 brief：完整中文 LDIF 离线工作台，白色面板/冷灰背景/深青主按钮，左侧行号编辑器、右侧诊断和审阅；顶部打开/复检/导出，三个独立选项；默认账号变更合成示例显示删除拦截。无图片素材、营销区域、账号头像或虚构指标。桌面目标 1536×1024，移动端按相同内容纵向排列。

## 设计系统与组件

- 背景 #f5f7f8；面板 #fff；正文 #172b2b；次级文字 #627777；边界 #dbe3e6；主色 #17665f；错误红 #ac3033。圆角 7～8px，无大阴影。
- 字体使用系统 Segoe UI / Microsoft YaHei，代码 Consolas；桌面标题 36px，编辑内容 17px/26px。移动端控件与代码分别缩小，保留可操作尺寸与横向编辑滚动。
- App 组合布局；Editor 管源文件和定位；Results 管可访问的结果标签与列表；useWorkbench 管输入版本、Worker 生命周期和导出。Icon 是统一描边的可缩放界面图标；没有重绘生成的品牌素材。
- 允许的主文案来自概念图：MoonLDIF、目录文件预检工作台、文件仅在本机处理、检查文件，再执行变更、打开 LDIF、重新检查、导出新文件、三个检查选项、源文件、诊断、变更审阅、定位原文、两个页脚声明。计数和状态必须来自核心结果。

## Fidelity ledger

| 比较点 | 参照与渲染核对 | 处理 |
|---|---|---|
| 页面结构 | 顶栏、标题操作区、设置、状态条、双栏、页脚 | 保留结构；手机改为纵向，未增加营销区 |
| 面板与颜色 | 白底、冷灰外层、青色按钮、浅红拦截 | 按设计色值实现；无背景图片或额外渐变 |
| 字体密度 | 初次渲染右栏和编辑器偏小 | 提高桌面字号，并检查计算样式为 36px 标题 / 17px 编辑器 |
| 编辑器位置 | 行号、原文高亮、默认删除行 | 修复自动聚焦造成的蓝色选择；仅用户点击定位时选中全文 |
| 控件与图标 | 三主按钮、原生选择器、复选框、线形图标 | 一致组件；状态改变时真实启用/禁用；标签支持键盘箭头/Home/End，修复 Ctrl+Home 被截获 |
| 文案差异 | 概念省略示例注释、只给操作起始行、缩短 DN | 有意保留真实文件注释、完整操作行范围和完整 DN；避免概念数据取代真实分析结果 |
| 必要新增信息 | 浏览器资源上限、失败/旧结果失效、分析不完整和截断提示 | 作为功能与状态必须信息补入；不属于装饰文案 |
| 手机 | 390×844 无页面横向溢出；源文件可独立横向滚动 | 首屏和审阅区域分开截图，未把 IAB 全页拼接异常当作布局缺陷 |

同一轮使用 view_image 对概念图与最新桌面/手机截图直接比较。边界、密度、主按钮、字体、图标、源位置高亮和面板顺序已核对；采用系统字体，字形不声称与生成图片像素一致。已修复的差异见上表。功能性文案与真实数据是明示差异。

QA 流程：默认删除拦截 → 定位属性删除 → 更改策略使旧结果失效 → 重新检查 → 下载实际文件并用 CLI 比较模型；另测坏名称修复、中文/二进制文件、坏 UTF-8、超限文件、外部引用、两个兼容选项和快速编辑旧结果阻断。下载事件观察超时但磁盘文件真实存在且内容比对通过；单次只读选择器观察超时后通过新 DOM 确认状态，没有重启页面冒充通过。
